系列說明

《天主教主日感恩祭典》依羅馬天主教主日讀經三年循環整理，分為甲年、乙年、丙年。每一主日收錄讀經一、讀經二與福音的經文來源、靈修內容整理，以及對應的 YouTube 影片連結。

本網站以「聖言 → 理解 → 反省 → 生活實踐」為方向，方便主日前預習、彌撒後複習，以及個人靜心與團體分享。未完成或尚未確認的資料不以推測補寫，可透過 Admin 模式逐步新增。

說明：「內容」欄以原創摘要／默想為主，不重製完整聖經譯文；經文正文請以正式天主教聖經及當地主教團禮儀用書為準。

Admin 編輯模式

登入後可直接編輯主日名稱、季節、三篇讀經的經文來源、內容與 YouTube 網址，也可新增主日並下載更新後的單一 index.html。

此為靜態網站的便利編輯鎖，不是伺服器級安全機制；公開部署的 HTML 原始碼仍可被檢視。
